# E-Commerce Product & Order Management System

A object-oriented Java application implementing core principles (**Encapsulation, Abstraction, Inheritance, and Polymorphism**).

## Features
1. **Encapsulation & Abstraction**: Secure personal information (`User`, `Customer`, `Address`) with controlled accessors.
2. **Customer Pool & Advanced Queries**: Add, delete, and query customers by name, city, phone number, and email.
3. **Product Catalog & Flexible Filtering**: Multi-parameter search queries (by ID, Name, Price, Price Range, Company Name).
4. **Authentication**: Customer registration and secure login.
5. **Shopping Basket & Orders**: Add items to cart, compute order amounts (Order Amount + Shipping Charge), and track status lifecycles (`CREATED_AND_RECEIVED`, `DISPATCHED`, `COURIER_AGENT_IN_TRANSIT`, `DELIVERED`, `RETURNED_AND_RECEIVED`).
6. **Polymorphic Payments**: Flexible payment processing (`UPI`, `Credit/Debit Card`, `COD`).
