# SDLC Explained - Study Notes Collection

## Overview

This PDF is a  focused on Software Development Life Cycle (SDLC), Agile methodology, Scrum practices, and Jira work management concepts. It is designed especially for software testers, QA engineers, and entry-level software professionals.

The document explains concepts using simple English and real-world examples such as login systems, Facebook-like applications, and college student registration systems.
